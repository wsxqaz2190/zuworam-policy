# zuworam-policy | 주워람 개인정보처리방침

**주워람 서비스의 개인정보처리방침과 계정·관련 데이터 삭제 요청 방법을 공개하는 저장소입니다.**

주워람은 브랜드별 할인·행사 정보를 확인할 수 있는 서비스입니다. 이 저장소의 웹페이지는 GitHub Pages를 통해 제공하며, 이용자는 앱에 로그인하지 않고도 개인정보 처리 기준과 문의 방법을 확인할 수 있습니다.

## 제공하는 안내

- 개인정보의 처리 목적과 항목, 보유 기간 및 파기 방법
- 개인정보의 제3자 제공, 외부 서비스 이용 및 처리업무 위탁
- 주변 매장 찾기에 사용하는 위치정보의 처리 방식
- 기기·브라우저에 저장되는 정보와 삭제 방법
- 이용자와 법정대리인의 권리 및 행사 방법
- 개인정보 보호조치, 보호책임자와 문의처
- 계정 및 관련 데이터 삭제 요청 절차

현재 개인정보처리방침의 시행일은 **2026년 11월 8일**입니다. 자세한 내용은 공개 웹페이지의 개인정보처리방침 본문을 확인해 주세요.

## 계정 및 관련 데이터 삭제 요청

앱에서 **내 정보 → 설정 → 계정 탈퇴**로 이동해 요청할 수 있습니다.

앱을 삭제했거나 로그인할 수 없는 경우에는 **[zuworamhelp@gmail.com](mailto:zuworamhelp@gmail.com)**으로 요청해 주세요. 가입에 사용한 Google 계정의 이메일 주소로 서비스명, 가입 이메일 주소 및 삭제 요청 내용을 보내면 됩니다. 비밀번호나 일회용 인증번호는 보내지 마세요.

운영자가 본인 여부를 확인한 뒤 삭제를 처리하며, 이메일 요청은 처리 완료 후 회신으로 결과를 안내합니다. 앱 삭제만으로 서버의 회원 계정이 삭제되지는 않습니다.

공개 웹페이지에는 Gmail·메일 앱에서 요청 메일을 작성하는 링크와 이메일 주소 복사 기능이 있습니다. 페이지 주소 끝에 `#account-deletion`을 붙이면 삭제 요청 안내로 바로 이동할 수 있습니다.

## 파일 구성

| 파일 | 용도 |
| --- | --- |
| `index.html` | 개인정보처리방침과 계정 삭제 요청 안내가 담긴 웹페이지 |
| `.nojekyll` | GitHub Pages에서 정적 파일을 그대로 제공하기 위한 설정 파일 |
| `README.md` | 저장소 소개와 이용 안내 |

별도의 설치나 빌드 없이 `index.html`을 브라우저에서 열어 확인할 수 있습니다. 페이지는 HTML·CSS·JavaScript로 구성되며, 모바일과 PC 화면에 맞춰 표시됩니다. 외부 폰트나 방문자 분석 도구를 사용하지 않습니다.

## 문서 관리

개인정보 처리 기준이 변경되면 `index.html`의 본문과 시행일을 함께 수정하고, 앱에 표시되는 개인정보처리방침에도 같은 내용을 반영합니다. 변경 내용과 적용일은 앱 또는 공개 웹페이지에서 안내합니다.
